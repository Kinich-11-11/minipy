### 本轮踩的坑（下轮注意）

- **callfn 有两条实路径**（IFELSE 一侧 callfnW 完整副本、一侧内联）——钩子必须两份
  都插，且可做"各恰好 1 份"的数量断言。
- **共享块 = 多主**：一个表达式块树喂多个挂点会坏（webfix/求值），每个使用点用
  工厂函数现场重建。
- **indexget 的 igev 是全局 scratch**：跨 callmeth 使用的值先快照到私有变量，否则方法
  体内的嵌套 indexget 会覆盖它。
- **合成 token 的 `count=1` 会泄漏**（fpush/fpop 不保存 count）——objiter/切片进出都要
  保存/恢复 count，否则下一个 eval 空区间报 missing expression。
- **gslice 元素级重编码破坏容器元素**（`yield 1, 2` 被拆段）——全新游标直接按 L 重释。
- **跨用例游标污染**：GIt/GId/ItSrc/ItPos/GErr* 已补进 RUN 启动清理。
- `REPEATU` 的 stop 判定发生在 body 之前——括号匹配的深度减法放 body、条件看自增前
  深度（fstr 内扫第一版过冲栽在这里）。
- `find()` 返回 id 数组；`spliceAfter` 只收单 id（要 `chain`）；补丁建的块没有
  parent 指针（找宿主 IF 扫 SUBSTACK 头）。

### §A.2 详情

* **B1 `is not`** —— `print(1 is not 2)` → `False`（应 True）；`x is not None` 恒 False；
  且 `is` 对值相等的不同对象返回 True（`[1] is [1]` → True，按值比较）。
  `while cur is not None` 循环体一次不执行 → **静默返回空**。`is None` 正常，单修 `is not` 分支。
* **B2 append 实参接收者泄漏** —— `lst.append('abc'.upper())` →
  `AttributeError: 'list' object has no attribute 'upper'`（在宿主 list 上找方法）；
  `acc.append(other.pop(1))` → pop 竟在 `acc` 上执行（IndexError）。
  内置函数作实参正常（`append(len('ab'))`、`append('+'+str(x))`），`join`/`update` 实参正常
  ——仅 **list.append（及同族变异方法）的实参**里再调用方法时接收者错位。
  修一处 callmeth 实参求值上下文保存，预计救回 5+ 例。
* **B3 filter 带谓词全坏** —— `list(filter(ev, [1,2,3,4]))`（ev 具名函数或 lambda）
  → `[True, False, False, False]`（**静默错值**）。581 套件只测过 `filter(None, …)`。
  **修复时顺手把谓词形式加进正式套件防回归。**
* **B4 多参 lambda** —— `fold(lambda a, b: a + b, xs, 0)` →
  `SyntaxError: lambda needs a colon`。单参内联 OK；`f = lambda a, b: …` 赋值形式 OK；
  dict 值形式同炸 → 解析器按参数个数走了不同路径。
* **B5 lambda 捕获"参数作可调用"失败** —— `def ap(f, v): return lambda x: f(x) + v`
  → 调用时 `NameError`。捕获普通变量（M18）、捕获列表 OK；`f(g(x))` 双可调用同炸。
* **B6 构造实例 self 重绑** —— `return W7(self.x + k, self.y + k)` →
  `AttributeError: 'W7' object has no attribute 'x'`（self 被提前重绑为未初始化新实例）。
  单实参 OK、全字面量实参 OK。**workaround 已验证：先存临时局部变量再构造。**
* **B7 init 改类属性毒化方法表** —— `def __init__(self): K.n += 1` 之后该类**任何**
  实例方法调用报 `NameError: name '.bump' is not defined`（名字带前导点）。
  `__init__` 只赋实例属性正常、无 `__init__` 正常、两实例正常。
* **B8 属性持对象分派错位** —— `self.e = E()` 后 `w.drive()` 报
  `E has no attribute drive`（外层类上明明存在）。
* **B9 元组赋值 RHS 含 `%`** —— `x, y = y, x % y` 单条即 `ZeroDivisionError`；
  纯交换、RHS 含 `+`、常量 RHS 正常 → 疑似逐元素交错求值。
  workaround：临时变量（M3 通过）。
* **B10 dict 字面量作实参污染** —— `recs.append({'name': f[0]})` →
  recs 变 `['a', '3', {'name': 'a'}]`（**静默**，外层列表元素被拖进实参）。
  同字面量赋给变量正常；值为纯变量正常。
* **B11 括号字符串 dict** —— `d = {')': '(', ']': '['}` → `SyntaxError: expression`。
  疑似 tokenize 对字符串**内容**做了括号深度计数。
* **B12–B14** —— `__contains__` 未接入 `in`（`TypeError: in requires strings`，`__len__` 正常）；
  `Exception.__init__(self, msg)` 不可调用（绕法：子类不调 base init 直接存属性，
  `str(e)` 与两参 args 行为均正确）；`hasattr` 缺失。
* **探针设计教训** —— 探针文件里**各用例不共享全局**：跨用例引用前面用例定义的名字会
  假失败（本轮 P13/M17/U3 三个"失败"即此，已排除）。

## 1. 生成器对象标识（剩余约 2 例）

- `cov7 generator short circuit`（any/all 求值不短路）——**不修**：genexp 仍急切物化，
  副作用顺序无法对齐，要真惰性（不可在块级 warp 模型里暂停函数体）。
- `covZ genexp is a list`（文档已声明的偏差）——`print(g)` 输出 `[0, 1, 2]`，
  CPython 是带地址的 `<generator object ...>`，逐字节对比不可过。

> 已落地：genexp 带 G 游标（`next(g)` 后 `list(g)`、comprehension 复用、sum 消费、
> join 实参）、生成器函数错误延迟到耗尽。生成器**函数**的游标语义（P497）+ 本轮的
> G 化共同覆盖了 `covY`/`cov7` 的全部既有用例。

## 2. `list(实例)`（迭代器协议收尾，约 1 例）

- `cov7 iterator protocol on custom class`：`list(It())` → `TypeError: 'It' object is not
  iterable`。objiter 已可用（`for v in it`、`next(it)`、`it[1:]` 都对），问题只在 callfnW
  的表达式上下文里 objiter 的合成 token/count 与内层求值互踩（missing expression）。
  可试：把 O→L 转换提到 callfnW 实参预求值之后、分支分发之前；或合成调用改走
  fpath 式临时全局名。

## 3. 返回值别名（约 2 例 + 新表现，未动，纯静默）

- `cov5 function modifying global list` / `default mutable argument`
- **新表现（§A）**：递归 flatten 即使先用临时变量接住递归结果再迭代
  （`inner = fl2(item); for sub in inner:`），输出仍是 `[3,4,5]×4` 型重复——
  递归帧的局部列表疑似跨帧共享身份（复现 Q22/N6）。
> 值都是编码串快照，修它要给容器引入引用语义，动面大。

## 4. RLE 串行污染（约 1 例，**本轮新诊断**）

- `cov8 realistic: run length encoding`：单程序无法复现；套件里 `cov8` 的
  "while else"（第 3 例）+ "nested loops break and continue"（第 4 例）连跑之后，
  后续函数内 `while + if/else` 在条件为真的首轮**两个分支都执行**（循环体内加一行
  print 探针即消失——海森bug）。v4.202 已存在，非本轮回归。根因在循环/else 状态机的
  跨用例残留（RUN 启动清理清单之外还有变量泄漏），需要专门排查。

## 5. 实例 `repr` 的 `__main__.`/地址（约 2 例，**不建议修**）

- `cov6 instance in dict and list`、`covY repr fallback for print`
> `<__main__.X object at 0x…>` 的地址逐字节对比下不可能匹配 CPython，修了也过不了。

## §10. 暂缓项（文档已声明 / 数值底座 / 低频 / 用例不合法）

| 条目 | 现状 | 缓放理由 |
|---|---|---|
| 大整数精度 | `cov1 big int precision`、`divmod big`、`integer division precision`、`cov10 int to str of very large` 等 | 文档 §2 已声明（JS number 失真） |
| 十进制浮点模型 | `cov1 round`→2.68、`sum of floats`、`cov10 round returns` | 同上主动取舍 |
| 浮点显示 | `cov1/covX/cov10 float trailing zeros`、`negative zero`、`large and small floats` | 触面广，等数值批次 |
| `print(sep='',end='')` | `covD sep empty with end empty` | 极窄边界 |
| `pow(x)` 报错用例 | `covD`/`covZ pow one arg` | 用例本身缺 try/except，非真问题 |
| `assert 1==2,'msg'` 裸跑 | `covZ assert with message` + 补充同名 | 用例无 expectError 标记；v4.203 行为已与 CPython 一致 |
| `type e equals E` | 补充 | 用例本身不合法（v4.200 已声明） |
| `frozenset` | `cov4 frozenset if supported` | 文档 §2/§3 已列 |
| `len(range)` / `range` 相等 | `cov5 builtin range forms` | 低频 |
| `format negative and sign` | `cov10` | 用例缺 try（CPython 抛 ValueError） |
