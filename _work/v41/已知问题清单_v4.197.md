# MiniPy 已知问题清单（基于 v4.197 实测）

**构建**：`MiniPy_v4.197.sb3`（2026-10-25，895 KB，32,420 块）
**对照**：CPython 3.14（oracle），15 套 581 例 + 补充 82 例，串行、各自私有临时文件。
**总量**：
- 581 例中 **73** 失败
- 82 例补充中 **21** 失败（其中 `pow one arg` 1 例 MiniPy 已对，只是测试用例缺 `try/except`，非真问题）
- **真实失败合计 ≈ 93**

> 排名判据：**影响体验（静默错 ≫ 报错） × 覆盖广度（学生日常写法出现频率）**。
> 所有结论均由 `runall.mjs`/`run_iso.mjs` 实测，逐例用 `cmp131.cjs`/`gdiff.cjs` 核验。

### 重要更正（上一版清单的误判）

- `cov6 builtin exception messages` 的真正根因不是"异常消息构造"，而是 calluser 报错分支用
  `stop this script` 跳过收尾 ⇒ 帧栈/cdepth 错位 ⇒ 顶层反复执行 handler 行。v4.197 由 P485 修掉，
  该缺陷**自 v4.182 起就存在**（v4.181 正确）。

## 1. 生成器（剩余约 8 例）

容器是"编码字符串 + 别名表"，生成器是**急切求值**：调用时跑完 body 收集 `GYield`。
`next()`/`list()` 的游标已能复用（P449/P461），新值会作废旧游标（P481，v4.197）。

- `cov7 nested generator functions` → `[1, 2, 10, 20]`（应为 `[10, 20]`）
- `covC nested generator yields`、`covY nested generator yields`（同上，共 3 例）
- `cov7 generator short circuit`、`cov7 generator expression vs list comp`、
  `cov7 comprehension reusing a generator`、`covY comprehension over generator function`
- `cov7 iterator protocol on custom class`、`cov7 generator in for loop`、
  `cov7 generator exception propagation`

> 上一轮遗留的 `_work/v41/p480.txt`（基准栈）就是冲"嵌套生成器"去的，但压栈被插进了
> calluser 的参数绑定循环（0 参函数不执行），会让所有生成器返回 `[]`。修法在文件注释里：
> 压栈放到 calluser 入口、出栈放收尾段；不要再替换参数循环里的那句 `deletealloflist`。

## 3. 例外实例模型（约 7 例）

拿到的 `e` 仍是消息串而非异常对象。

- `covC exception instance identity` → `False`（应为 `True`）
- `covZ exception instance type` → `False`；`covY type equality with class` → `False`
- `cov6 custom exception with attributes` → `AttributeError: code`
- `cov6 exception str and repr`、`cov6 exception hierarchy catching base`、`cov6 assert statements`
- 补充 `type e equals E`、`except as e is exception object`、`custom exception init attr`

## 4. 闭包返回 / `nonlocal`（约 4 例）

- `covC closure returned and called` → `NameError: n`
- `covY closure returned lambda called` → `NameError: n`
- `covC nonlocal keyword` → `SyntaxError: unsupported statement`；`cov5 closure counter attempt without nonlocal`
- 补充 `closure returned`、`nonlocal counter`

## 5. 运算符重载 `__lt__` / `len` / `__getitem__`（约 5 例）

## §11. 暂缓项（文档已声明 / 数值底座 / 低频）

| 条目 | 现状 | 缓放理由 |
|---|---|---|
| 大整数精度 | `cov1 divmod big`→`49`(应为56)、`int to str of very large`→`21`(应为31) 等 6 例 | 文档 §2 已声明（JS number 失真） |
| 十进制浮点模型 | `cov10 sum of floats`→`0.6000000000000001`、`cov1 round`→`2.68`(应为2.67) | 同上主动取舍 |
| 浮点显示 | `cov1 float literal trailing zeros`→`3.50`、`cov10 float printing`→`2.50` | 触面广，等数值批次 |
| `print(sep='',end='')` | `covD` → 空（应为 `xy`） | 极窄边界 |
| genexp 立即求值 | `covZ genexp is a list`→`[0,1,2]` | 文档主动声明偏差 |
| `repr` 回退 / `frozenset` | `covY repr fallback`、`cov4 frozenset`→`ne` | 文档 §2/§3 已列 |
| `pow(x)` 报错用例 | `covD`/`covZ pow one arg` | 用例本身缺 try/except，非真问题 |
| realistic 用例 | `cov8 run length encoding`→静默错、`cov8 class based bank`→`SyntaxError` | 根因落生成器/解析 |
