## 1. 浅拷贝 `[:]` / `.copy()` 是深拷贝（纯静默，最该先修）

复制一份后改副本，原对象也被改；二维结构尤其隐蔽。

- `cov3 shallow copy method`：`b=a[:]; b[0].append(2)` → `[[1,2]] [[1,2]]`（应为 `[[1]] [[1,2]]`）
- `cov3 slice copy vs alias`、`cov4 dict copy shallow`、`covX list slice/copy method depth`/`dict copy depth` 共 **6 例**
- `covC copy is deep`：`[[1]] [[1,2]]`（应为 `[[1,2]] [[1,2]]`）
- `gap131 copy deep not shallow`

> 学生预期"复制 = 独立副本"，MiniPy 给的是别名。每个数据结构练习都可能踩，且**不报错**。

## 2. 生成器 / `next()` 无迭代器状态（严重静默，且有回归）

容器是"编码字符串 + 别名表"，没有游标；`next()` 不前进、genexp 被当 list 立即求值。

- `cov7 generator short circuit` / `generator expression vs list comp` / `comprehension reusing a generator` / `generator in for loop` / `iterator protocol on custom class` / `nested generator functions` / `generator exception propagation` / `yield from if supported`
- `covC generator exhaustion` / `nested generator yields`
- `covY generator exhaustion twice` / `nested generator yields` / `comprehension over generator function`
- `gap131 generator exhaustion` / `yield from`（共约 14 例，多静默）

> ⚠️ v4.196 **新回归 2 例**：`cov7 generator return value stops iteration`→`[]`（应为`[1]`）、`cov7 yield inside condition and loop`→`[]`（应为`[0,2,4,6]`）。

## 3. 返回值别名（仅剩全局列表 / 默认可变参）

嵌套函数返回别名、闭包捕获已修；**全局可变列表 append 后返回、默认可变参仍漏**。

- `cov5 function modifying global list` → `[1] [1,2]`（应为 `[1,2] [1,2]`）
- `cov5 augmented assign to global inside function` → `1`（应为 `ule`）
- `cov5 default mutable argument` → `[1] [2]`（应为 `[1,2] [1,2]`）

## 4. 异常实例模型（仅剩实例身份/属性）

异常类可捕获已修；拿到的 `e` 仍是消息串而非异常对象。

- `covC exception instance identity` → `False`（应为 `True`）
- `covZ exception instance type` → `False`
- `cov6 custom exception with attributes` → `AttributeError: code`
- `cov6 exception str and repr` → `NameError: ValueError`
- `cov6 exception hierarchy catching base`、`gap131 type e equals E` / `except as e is exception object` / `custom exception init attr`（约 8 例）

> ⚠️ v4.196 **新回归 1 例**：`cov6 builtin exception messages` 把 message 串循环重复输出（疑似异常消息构造改动副作用），作者需回看。

## 5. 闭包返回 / `nonlocal`（捕获已修，剩返回+nonlocal）

- `covC closure returned and called` → `NameError: n`
- `covC nonlocal keyword` → `SyntaxError: unsupported statement`
- `covY closure returned lambda called` → `NameError: n`
- `cov5 closure counter attempt without nonlocal`（→ `1 1`）、`gap131 closure returned` / `nonlocal counter`（约 7 例）

## 6. 运算符重载 `__eq__/__lt__` / `len`/`__getitem__`（add 已修）

- `cov6 operator overloading lt for sort` → `TypeError: '<' not supported`（应为 `['1','2','3']`）
- `cov6 operator overloading len getitem` → `SyntaxError: expression`
- `cov6 calling method stored in variable` → `AttributeError: f`（应为 `6`）
- `gap131 operator overload lt sorted`（约 6 例）

## 7. 内建名当值（`type(1)==int`、`apply(str,4)`）

- `cov5 function as argument` → `NameError: str`
- `cov5 builtin type names` → `NameError: int`（第二行）
- `gap131 builtin as value apply str` / `type identity equals int`（约 4 例，多为 `NameError`）

## 8. `map`/`filter` 首参须函数名、`range` 步进

- `cov5 builtin map filter reduced` → `TypeError: map()/filter() first argument must be a function name`
- `cov5 lambda forms`（`map` 段同样报错）
- `cov5 builtin range forms` → `SyntaxError: parentheses`（步进 `range(5,1,-2)` 未解析；应为 `[5,3,1]`）

## 9. 隐式拼接续行 / 反斜杠换行（尾逗号已修）

- `cov9 backslash in string is not continuation` → `a b`（应为 `ab`；反斜杠未当续行）
- 隐式拼接、跨行拼接、调用/字面尾逗号 **v4.196 已全部修掉**。

## 10. 字典内 `repr` / 方法存变量调用（小尾巴）

- `cov6 instance in dict and list` → `x [<Item object>, ...]`（应为 `<__main__.Item object at ...>`；仅 str 形式不同，属文档偏差）
- `covY method returns self attribute pop` → `<S object>`（应为 `2`）

## §10. 暂缓项（覆盖也广，但文档已声明 / 数值底座 / 低频）
