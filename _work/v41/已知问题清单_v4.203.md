# MiniPy 已知问题清单（基于 v4.203 实测）

**构建**：`MiniPy_v4.203.sb3`（2026-10-28，34,079 块）
**对照**：CPython 3.14（oracle），15 套 581 例 + 补充 82 例，串行、各自私有临时文件。
**总量**：
- 581 例中 **36** 失败（v4.202：41）
- 82 例补充中 **8** 失败（v4.202：9）
- **真实失败合计 ≈ 41**（v4.202：≈48；另有 3 例"用例不合法"）

> 排名判据：**影响体验（静默错 ≫ 报错） × 覆盖广度（学生日常写法出现频率）**。
> 所有结论均由 `runall.mjs`/`run_iso.mjs` 实测，逐例用 `cmp131.cjs`/`gdiff.cjs` 核验。

### 本轮新增补丁（p500–p503）

* **P500** assert：execute 加分支（`pending==0` 守卫前，P104/P499 同款挂点）。深度 0 找
  第一个逗号拆条件/消息，truth() 假值时报 `AssertionError: <msg>`（无消息报 `AssertionError`）。
* **P501** ULE 产生侧：regdef 末尾静态扫描函数体（tokenize 期间保存/恢复 Tok/Kind/error）
  收集本地名/排除名（FnLoc*/FnXc* 扁平区间表）；lookup 主扫描后统一算 ubF（严格本地名）
  与 ubR（严格本地 且 未绑定 或 命中继承槽 `found < lenL(FN)-FrBase[top]+2`），ubF 时跳过
  P383 闭包回退；`FrBnd`/`FrBndC` 记录每帧赋值过的名字（assign 标记、calluser 压入/截断）；
  atom 的 NameError 兜底与三个增强赋值分支的 `found==0` 门外按 ubR 抛
  `UnboundLocalError: cannot access local variable 'x' where it is not associated with a value`。
* **P502** finally：trycatch tailDone 的重抛 `error=tfm` 加 `retflag != 1` 守卫——
  finally 尾块里的 return 吞掉在途异常（CPython 语义）。
* **P503** 链式下标增强赋值：execute 下标 aug 分支的 augop=='' 兜底——全 token 扫描
  （三种括号计深、跳字符串）在深度 0 找 augop、要求前一 token 是 `]`，改写 token 成普通链式写。

### 本轮踩的坑（下轮注意）

* **REPEAT_UNTIL 语义 = 条件为假就执行循环体**。"while x > 0" 必须写
  `REPEATU(NOT(GT(x, 0)))`；写反时删空列表无限循环（del last 对空表 no-op），
  VM 卡死在一步 warp 里，表现为 run.mjs 20 秒超时、status 停在 Running。
  本轮 FrBnd 截断循环栽在这里；定位靠 V41_TRACE 构建看最后一条 EXECEND。
* builder 的 `IF(cond, ids)` 只有 2 参——`IF(c, [a], [b])` 的第三参被**静默丢弃**
  （本轮丢了整段扫描规则分支）。多分支必须 IFELSE；新工具 `zcheckif.cjs` 扫 3 参 IF。
* 数组字面量元素带分号（`[FAILB(...);]`）是语法错误，V8 报在几百行之外；
  定位工具 `zmatch.cjs`（括号配对、字符串/注释感知）。
* JOIN 链多包一层（单参 JOIN）→ scratch-vm 把 undefined 拼进串（消息尾部多 "undefined"）。
* execute 的增强赋值有**三个**同构分支（`//`/`**`、`&|^<<>>`、`+=` 家族），改一个要想到另两个。
* `fail %s` 的消息文本在 join 链的**子块**里，`JSON.stringify(b.inputs)` 匹配不到；
  要用 exprReach 深扫（atom 的 NameError 兜底定位踩过）。

## 1. 生成器对象标识（剩余约 6 例，核心是 genexp 惰性）

- `cov7 comprehension reusing a generator` → `[0,1,2] [0,1,2]`（应 `[0,1,2] []`）
- `cov7 generator expression vs list comp` → `next(g), list(g)` 得 `0 [0,1,2]`（应 `0 [1,2]`）
- `cov7 generator short circuit`（any/all 求值不短路）
- `cov7 generator exception propagation`（body 在 next 时一次跑完）
- `cov7 iterator protocol on custom class`（`__iter__`/`__next__`，TypeError: not iterable）
- `covZ genexp is a list`（文档已声明的偏差）

> 方向：生成器**函数**的游标已修好（P497）；剩下全卡在 genexp 急切物化为 L
>（§10 已声明偏差）。v4.201 试过"P235 括号剥离点把内层含 for 的结果改标 G"，
> G 化本身成功但 `next(g)` 立刻 StopIteration（疑似 printargs 求值顺序/双重求值），
> 已回退。重试前先探明 `print(next(g), list(g))` 的实参求值顺序。

## 2. `format` 高级形式 / 嵌套 f-string（约 4 例，未动）

- `cov10 nested fstring in format`、`cov10 format nested spec and paths`（部分对）、
  `cov2 format errors caught`、`cov10 format negative and sign`（用例缺 try，见 §10）

## 3. 返回值别名（约 2 例，未动，纯静默）

- `cov5 function modifying global list` / `default mutable argument`
> 值都是编码串快照，修它要给容器引入引用语义，动面大。

## 4. 其他（约 4 例，未动）

- `cov6 operator overloading len getitem`（`__len__`/`__getitem__` → SyntaxError: expression）
- `cov8 realistic: class based bank`（根因落解析/生成器）
- `cov8 realistic: run length encoding`（itertools/分组写法）
- 补充 `tuple element path alias`、`next builtin missing`（对 list 直接 next 的序语义）

## 5. 实例 `repr` 的 `__main__.`/地址（约 2 例，**不建议修**）

> `<__main__.X object at 0x…>` 的地址逐字节对比下不可能匹配 CPython，修了也过不了。

## §10. 暂缓项（文档已声明 / 数值底座 / 低频 / 用例不合法）

| 条目 | 现状 | 缓放理由 |
|---|---|---|
| 大整数精度 | `cov1 big int precision`、`divmod big`、`integer division precision`、`cov10 int to str of very large` 等 | 文档 §2 已声明（JS number 失真） |
| 十进制浮点模型 | `cov1 round`→2.68、`sum of floats`、`cov10 round returns` | 同上主动取舍 |
| 浮点显示 | `cov1/covX/cov10 float trailing zeros`、`negative zero`、`large and small floats` | 触面广，等数值批次 |
| `print(sep='',end='')` | `covD sep empty with end empty` | 极窄边界 |
| `pow(x)` 报错用例 | `covD`/`covZ pow one arg` | 用例本身缺 try/except，非真问题 |
| `assert 1==2,'msg'` 裸跑 | `covZ assert with message` + 补充同名 | 用例无 expectError 标记；v4.203 行为已与 CPython 一致（err==pyerr），Output 有错误行导致逐字节对比不过 |
| `type e equals E` | 补充 | 用例本身不合法（v4.200 已声明） |
| `frozenset` | `cov4 frozenset if supported` | 文档 §2/§3 已列 |
| `len(range)` / `range` 相等 | `cov5 builtin range forms` | 低频 |
| `format negative and sign` | `cov10` | 用例缺 try（CPython 抛 ValueError） |
