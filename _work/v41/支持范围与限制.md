## 1. 支持的代码（与 CPython 逐字一致）

### 词法 / 语句形态
`#` 整行注释与行尾 ASCII 注释、空行；反斜杠续行、圆括号内跨行；**任意空格缩进宽度**（v4.85 P158 起）
与 **TAB**（v4.86 P159 起）；
单行复合语句 `if a > b: print('x')`（运行前会被拆成两行）；顶层分号多语句 `a = 1; b = 2`；
字面量：整数、浮点（`3.5`、`0.5`）、**科学计数 `1e3` / `1.5e-7` / `1e300`**（v4.49 起任意指数都认，数值与 CPython 逐位一致）、**`0x10 / 0b101 / 0o17`**、单/双引号字符串、`True/False/None`。
**字符串字面量的内容可以是标点本身**（**v4.111 P184** 起）：`len(',')`、`len('x' + ',' + 'y')`、`len(','.join(['ab']))`、
`[',', 'a']`、`(',', 'a')`、`{',' : 1}`、`g(',')`、`for ch in ','`、`'a,b'.split(',')`、`'a,b'.replace(',', ';')`
都按 CPython 算（P184 之前这些会被当成真的逗号分隔符而报 `NameError`/`SyntaxError`；判据是 token 的
`Kind != "S"`）。
浮点**排版**与 CPython 一致（v4.49）：`-4 ≤ exp10 < 16` 定点、否则科学计数且指数至少两位（`1e16`、`1e-05`、`1.5e-07`），`-0.0` 保号，`float(1)` → `1.0`。

### 运算符
`+ - * / // % **`、一元 `-`、位取反 `~`；
比较 `== != < <= > >=`、**链式比较** `1 < 2 < 3`（**v4.95 P168** 起语义与 CPython 一致：`(a op1 b) and (b op2 c)`，每个操作数**只求值一次**、第一个为假的比较**短路**；`< > <= >= == != in is` 都能串，`1 < 2 < 3 or 9 < 1` 也对）；
`and or not`、`in / not in`（字符串、列表、字典）、`is / is not`；
位运算 `& | ^ << >>`（表达式里；**v4.121 P194 起收负数**：`& | ^` 按二补数算 —— 宽度取"刚好容纳两个操作数"的 2 的幂
（`2^(W-1) > max(|a|, |b|)`），负数映射成 `x + 2^W`、算完最高位为 1 的再减回 `2^W` ⇒ `-1 | 0`→`-1`、`-2 & 3`→`2`、
`-1 ^ 1`→`-2`、`-5 & -3`→`-7`；`<<`/`>>` 本来就对负数成立（乘 2 / `floor(x/2)`）⇒ `-1 << 2`→`-4`、`-3 >> 1`→`-2`；
**负数移位次数**报 CPython 的 `ValueError: negative shift count`。精度：映射在 `max(|a|, |b|) < 2^52` 时精确
（和不超过 2^53），再大就落到本工程固有的"大整数"限制。**v4.122 P195 起布尔也能用**：左侧是布尔不再报错
（`True | 1`→`1`、`1 & True`→`1`、`True << 2`→`4`，来自比较式的布尔同样可以），而且 `& | ^` 的**两个操作数原本都是布尔**时结果仍是布尔（`True | False`→`True`，`True | 1`→`1`）；`|` 也用于字典合并，见下）；
增强赋值 `+= -= *= /= %= **= //=` 与位运算增强赋值 `&= |= ^= <<= >>=`；
三表达式 `a if c else b`。
一元 `~` 与一元 `-`/`+`（v4.122 P195 起**也收布尔**：`~True`→`-2`、`~False`→`-1`、`-True`→`-1`；
`~` 后面直接跟正负号也可以：`~-1`→`0`、`~+1`→`-2`、`~-(2+3)`→`4`）。

### 内建函数
`print`（多参数、`sep=`/`end=`）、`len str int float abs round pow chr ord sum any all divmod repr list sorted(单参)`、**`enumerate`（v4.102 P175 起支持起始值 `enumerate(xs, start)`）**、**`zip`**、
`sum(xs[, start])`（**v4.99 P172** 起支持起始值）、**`bin`/`hex`/`oct`（v4.103 P176）**、**`reversed(x)`（v4.107 P180，返回反转后的列表）**、`min/max`（**多参数**与**单可迭代**两种形式）、`int(x, base)`（**v4.105 P178** 起收 `0b`/`0o`/`0x` 前缀）、`input()`；
**`max`/`min`/`sorted` 的可迭代形式也收字符串**（**v4.112 P185**：按**字符**迭代，`max('ba')`→`b`、`min('ba')`→`a`、
`sorted('ba')`→`['a', 'b']`、`sorted('ba', reverse=True)`→`['b', 'a']`；`max(5)` 报 `TypeError: 'int' object is not iterable`）。
**实参形式也补齐了**（**v4.113 P186**：`max(1, 2, 3)`→`3`、`max(1, 2, 3, 4)`→`4`、`max('a','b','c')`→`c`
（此前**漏看最后一个实参**，`max(1,2,3)` 给 `2`）、两实参 `max('a','b')`→`b`、`max([1],[2])`→`[2]`、`max((1,2),(1,3))`→`(1, 3)`）。
**嵌套调用也修好了**（**v4.114 P187**：`max(min(5, 2), 3)`→`3`、`min(max(1, 4), 2)`→`2`、`max(0, min(5, 10))`→`5`、
`max(min(max(1, 5), 3), 2)`→`3`；此前内层调用会冲掉外层的共享暂存）。
**`key=` 也支持了**（**v4.123 P196**：`min([3, 1, 2], key=lambda x: x)`→`1`、`max(['bb', 'a', 'ccc'], key=len)`→`ccc`、
`min([(1, 5), (2, 3)], key=lambda p: p[1])`→`(2, 3)`、`max(-1, -5, key=abs)`→`-5`（多个位置实参也行）、
`min('ba', key=…)` 按字符、`min({'b': 2, 'a': 1}, key=…)` 按键迭代；key 可以是 lambda、用户函数或
`len`/`abs` 这类**内建名**；键的比较走 `lcmp`（数字/布尔/字符串/元组/列表，混用报 CPython 的 `<` TypeError），
**相等时保留先出现的那个**；`min([], key=f)` 报 `ValueError: min() iterable argument is empty`、
`min(5, key=f)` 报 `TypeError: 'int' object is not iterable`、
`min([1], foo=1)` 报 `TypeError: min() got an unexpected keyword argument 'foo'`）。
`round(2.5)` 是**银行家舍入** ✓、`int(' 12 ')` 会去空白 ✓。

### 字符串
切片 `s[1:3]` 与**步长 `s[::2]` / 反向 `s[::-1]`**（含负下标）、`*` 重复、`+` 拼接、子串 `in`；
方法 `upper lower strip find count replace startswith endswith split join index title zfill isdigit isalpha format`、
**v4.109 P182 让 `join` 也收元组与字典的键**（`'|'.join(('x', 'y'))`→`x|y`、`','.join({'a': 1, 'b': 2})`→`a,b`；元组的编码与列表一致，P140 起通用；元素仍必须是字符串——v4.108 P181 起第一个非字符串报 CPython 的 `TypeError: sequence item 0: expected str instance, int found`）、
**v4.116 P189 起 `join` 收字符串（按字符）与集合**（`'-'.join('ab')`→`a-b`、`''.join('ab')`→`ab`、`'-'.join({'a'})`→`a`；
多元素的**字符串**集合在 CPython 里是哈希序、不保证一致），
**v4.106 P179 给 `count` 补上起始位置参数**；**v4.117 P190 又给 `index` 补上起始位置参数**（`'abca'.index('a', 1)`→`3`；
列表与元组的 `index(x, start)` 同轮补齐 —— 负起点按长度归一、超界报 `ValueError`，浮点起点报
`TypeError: slice indices must be integers or have an __index__ method`；**v4.127 P200 起 `end` 也有了**）；**v4.104 P177 又给 `find`/`rfind` 补上起始位置参数**；**v4.101 P174 又补 `rfind`/`rindex`/`casefold` 与 `strip`/`lstrip`/`rstrip` 的字符集形式**；**v4.94 P167 又补 17 个**：`ljust` `rjust` `center`（默认填充空格，`center` 的奇偶与 CPython 一致）、
`lstrip` `rstrip`（空白含空格/TAB/`\n`/`\r`）、`swapcase` `capitalize`、`partition` `rpartition`（返回三元组）、
`splitlines`（按 `\n` 切、丢弃尾部空行）、`removeprefix` `removesuffix`、`expandtabs`（默认 8，按列对齐）、
`isupper` `islower` `isspace` `isalnum`（ASCII；`''.isupper()` 为 `False`）；
**`s.split()`（无参）按连续空白切并丢掉空段**（v4.47）、`s.split('')` 报 `ValueError: empty separator`（v4.47）、
**v4.118 P191 起 `s.split(sep, maxsplit)` 生效**（`'a,b,c'.split(',', 1)`→`['a', 'b,c']`、`maxsplit=0`→`['a,b,c']`、
负数=不限；非整数 `maxsplit` 报 CPython 的 `TypeError: '<类型>' object cannot be interpreted as an integer`），
并修掉三处丢空字段的静默错（`''.split(',')`→`['']`、`','.split(',')`→`['', '']`、`'a,'.split(',')`→`['a', '']`）；
**v4.120 P193 起 `s.split(None)` 走空白切分器**（`'a b  c'.split(None)`→`['a', 'b', 'c']`、`''.split(None)`→`[]`，
与无参 `s.split()` 同一条路径）；
**v4.127 P200 补齐字符串接口的收尾**：`find` / `rfind` / `count` / `index` 现在都收
**`(sub, start, end)`**（字符串；列表与元组的 `index(x, start, end)` 同轮补齐，`end` 按 Python 切片钳位 ——
`'abcabc'.find('b', 2, 4)`→`-1`、`'abc'.find('', 5)`→`-1` / `find('', -1)`→`2`、`[1,2,1,2].index(2, 0, 2)`→`1`），
**负数 `start` 也按长度归一**（`'abcabc'.find('a', -3)`→`3`，v4.104/v4.106 的两实参内核以前答 0）；
**`s.split(None, maxsplit)` 生效**（`'a b  c'.split(None, 1)`→`['a', 'b  c']`、`maxsplit=0`→`['a b  c']`）；
**`rsplit` 三种形式齐全**（`'a,b,c'.rsplit(',')`→`['a', 'b', 'c']`、`(',', 1)`→`['a,b', 'c']`、
`'a b  c'.rsplit(None, 1)`→`['a b', 'c']`、`'  a   b  '.rsplit(None, 1)`→`['  a', 'b']`，空分隔符报
`ValueError: empty separator`）；
**v4.128 P201 收掉字符串方法的实参**：`replace(old, new, count)` 支持 **`count`**（负数=不限；少给实参报
`TypeError: replace() takes at least 2 positional arguments (N given)`；`count` 非整数报
`TypeError: '<真实类型>' object cannot be interpreted as an integer`），**空模式按 CPython 逐位插入**
（`'abc'.replace('', 'X')`→`XaXbXcX`、`'abc'.replace('', 'X', 2)`→`XaXbc`、`''.replace('', 'X')`→`X`）；
**`startswith`/`endswith` 支持 `start`/`end` 区间**（`'abc'.startswith('b', 1)`→`True`、
`'abc'.endswith('c', -1)`→`True`；区间规则是 CPython 的 `tailmatch`：`start` 不夹到 `len`、
`end < start` 直接 `False`，所以 `'abc'.startswith('', 5)`→`False` 而 `...('', 3)`→`True`）；
**位置实参收整数与布尔，`None` 表示"没给"**（`'abcabc'.find('a', None)`→`0`、`find('a', True)`→`3`），
别的（浮点、字符串、列表……）一律报 CPython 的
`TypeError: slice indices must be integers or None or have an __index__ method`（v4.127 及以前浮点会**静默算错**，
`'abcabc'.find('a', 1.5)` 答 `3.5`，字符串起点还会报错成 `'int' object cannot be interpreted as an integer`）；
**仍缺：`encode` / `translate` / `maketrans` / `format_map` / `isascii` / `isdecimal` / `isidentifier` /
`isnumeric` / `isprintable` / `istitle` 这些还没做的字符串方法**；
`%` 格式化 `%d %i %s %r %c %f %F %x %X %o %e %E %g %G`（含标志 `-` 左对齐、`0` 零填充、`+`/空格符号，宽度与
`.` 精度，**`*` 从实参取宽度/精度**，以及**映射键形式**：`'%05d'`、`'%+d'`、`'%8.3f'`、`'%-5d'`、`'%.2e'`、
`'%*d' % (5, 3)`、`'%(a)s=%(b)d' % {'a': 'x', 'b': 3}`，v4.72–v4.74 P145/P146/P147）、非法转换符报
`ValueError: unsupported format character 'q' (0x71) at index 1`、多余参数报
`TypeError: not all arguments converted during string formatting`、映射缺键报 `KeyError: 'zz'`
（v4.79 P152 补上 **`%g`/`%G` 通用格式**：`'%g' % 0.00001`→`1e-05`、`'%g' % 100000000`→`1e+08`、
`'%.3g' % 1234.5`→`1.23e+03`、`'%10.4g' % 3.14159`→`     3.142`）、
**`%c` 收整数或"一个字符的字符串"**（v4.88 P161：`'%c' % 'a'`→`a`、`'%c' % 65`→`A`、`'%c' % 'Z'`、
`'%s-%c' % ('x', 'y')`、`'%5c'`/`'%-5c'` 宽度照旧；类型错文案逐字对齐 CPython——
`TypeError: %c requires an int or a unicode character, not str`（`str`/`list`/`dict`/`None` 各报实际类型名）、
`.format`/f-string 侧不受影响（`'{:c}'.format('a')` 仍报
`ValueError: Unknown format code 'c' for object of type 'str'`，`'{:c}'.format(65)`→`A`））、
f-string 表达式 `f'{n} {n*2}'` 与**格式规格** `f'{x:.2f}'`、`f'{n:>5}'`、
`f'{s:*^7}'`、`f'{x:8.3f}'`、`f'{n:05d}'`（v4.78 P151 起与 `.format` 共用同一套规格解析）、
`'{} {}'.format(1, 2)`、`'{0} {1}'.format(3, 4)`、**关键字形式** `'{a}'.format(a=3)` /
`'{a}={b}'.format(a=1, b=2)` / `'{b} {a}'.format(a=1, b=2)`、**位置与关键字混用**（`'{} {a}'.format(1, a=2)`、
`'{a} {}'.format(1, a=2)`、`'{a} {b} {}'.format(9, a=1, b=2)`；顺序错时报
`SyntaxError: positional argument follows keyword argument`、重复关键字报
`SyntaxError: keyword argument repeated: a`、名字缺失报 `KeyError: 'a'`）、**参数里可以放任意表达式**
（下标 `a[1]`、方法调用 `'ab'.upper()`、内建调用、内联字典取键、元组下标——v4.77 P150 修掉了"收信者被
参数求值污染"的旧 bug）、**格式规格**（v4.78 P151：`[[fill]align]`（`<>^=` 与自定义填充）、`+`/空格符号、
`0` 零填充、宽度、`.` 精度、`d/f/s` 等类型符；`'{a:>5}'`→`    1`、`'{:*<6}'.format('ab')`→`ab****`、
`'{:^7}'.format('ab')`→`  ab   `、`'{:05d}'.format(-42)`→`-0042`、`'{:=5}'.format(-42)`→`-  42`、
`'{a:8.3f}'.format(a=3.14159)`→`   3.142`；v4.79 P152 又补上 **`g`/`G` 通用格式**（`'{a:g}'`、`'{a:.2g}'`、
`f'{0.00001:g}'`→`1e-05`）、**`b` 二进制**（`'{a:08b}'.format(a=5)`→`00000101`）、
**`%` 百分号**（`'{a:.1%}'.format(a=0.25)`→`25.0%`、`'{a:8.1%}'`→`   25.0%`）——`e`/`E`/`x`/`X`/`o`/`c`/`r`
本来就能用；**v4.80 P153** 又补上 **`!r`/`!s`/`!a` 转换**与 **`,`/`_` 千分位分组**——
`'{a!r}'.format(a='xy')`→`'xy'`、`'{a!r:>10}'`→`      'xy'`、`'{a:,}'`→`1,234,567`、
`'{a:,.2f}'`、`'{a:_}'`、`'{a:15,}'`；**v4.81 P154** 又补上 **`#` 备用形式前缀**（`'{a:#x}'`→`0xff`、
`'{a:#X}'`→`0XFF`、`'{a:#b}'`→`0b101`、`'{a:#o}'`→`0o10`、`'{a:#010x}'`→`0x000000ff`、`'%#x' % 255`→`0xff`）
与 **f-string 里的 `!r`/`!s`**（`f'{x!r}'`→`'ab'`、`f'{x!r:>8}'`、`f'{n * 2!r}'`）、
**十六/八/二进制要求整数**（`'{a:b}'.format(a=1.5)` 现在报错而不是打印 `1`）；**v4.82 P155** 又补上
**字段里的属性与下标路径**（`'{a.n}'.format(a=obj)`→`7`、`'{a.q.v}'`、`'{a.s!r}'`、`'{a[1]}'`→`8`、
`'{0[1]}'`、`'{a[k]}'` 字典键、`'{a[1][0]}'` 嵌套、`'{a.xs[1]}'` 属性+下标、`'{a[1]:>5}'` 带规格；
方括号里是**字面量**：全数字当整数下标，否则当字符串键，所以 `'{a[i]}'`/`'{a[-1]}'` 对列表报
`TypeError: list indices must be integers or slices, not str`，与 CPython 一致）；**v4.83 P156** 又把
**报错措辞**补齐：`.format`/f-string 的类型错报 CPython 的
`ValueError: Unknown format code 'd' for object of type 'str'`（`%` 侧保留 `TypeError: %d format: a real
number is required, not str` 这套并逐字对齐）、字段不足/越界报
`IndexError: Replacement index 1 out of range for positional args tuple`、自动与显式编号混用报
`ValueError: cannot switch from automatic field numbering to manual field specification`（具名字段不参与，
故 `'{a} {}'`、`'{a} {0}'` 仍合法）、
**嵌套字段**（v4.87 P160：规格里还能再放 `{...}`——`'{:{w}}'.format(3, w=5)`→`    3`、
`'{:{}.{}f}'.format(3.14159, 8, 2)`→`    3.14`、`'{:*>{w}}'`、`'{:0{w}d}'`；空名字用下一个自动位置参数、
全数字是显式下标、其它查关键字；越界报 `IndexError: Replacement index …`、缺名字报 `KeyError: 'w'`）、

## 3. 明确不支持（写了会报错或结果错）

**源码文本层面**
* **非 ASCII**：中文注释/标识符/字符串一律 `SyntaxError: ASCII text required`（渲染字库也只有 ASCII）。
* 缩进：**任意空格宽度都可以**（v4.85 P158 起：2 / 3 / 4 / 6 / 8 空格，只要一致就能开块；
以前强制 4 的倍数、2 空格报 `IndentationError: use 4 spaces`）；**TAB 也可以**（v4.86 P159：
TAB 缩进、行尾 TAB、字符串里的 TAB 都行，每个 TAB 记 1 个宽度——CPython 按 8 展开制表位，
但 MiniPy 只用"相对层级"，能跑就行）；多余缩进仍报
`IndentationError: unexpected indent`（前一行不是 `if`/`for`/`while`/`def`/`class`/`try`/`else` 等块开头时）。
TAB 与空格**混用**不报 `TabError`（比 CPython 宽松）。

**表达式 / 语句**
* **生成器表达式已支持**（v4.53：`t141.json` 18/18、`t143.json` 7/7）：`f(x for x in xs)`、
  `sum(x * y for x in xs for y in ys)`、`g = (x for x in xs)`、`for a, b in g()`、`a, b = g()` 都能用。
  **主动偏差**：MiniPy 把它**立即求值成列表**（与 `enumerate`/`zip` 一致），所以 `print(x for x in range(3))`
  打印 `[0, 1, 2]` 而不是 `<generator object at 0x…>`，`len(g)` 可用，`list(g)` 两次都拿到全部元素
  （CPython 第二次是空的）。
* 嵌套推导式、任意条 `for`/`if` 子句的推导式**已支持**（v4.52；`t139.json` 31/31）。
* ~~`yield i, i + 1`（yield 一个裸逗号元组）报 `TypeError: use str(number)`~~ —— **v4.47 P116 已修**
  （yield 处补 `hascomma` + `tuplelit`）。

**集合类型**
* 集合方法/运算符已支持（v4.51，v4.55 补 `issubset`/`issuperset`、无参 `set()`）：见上面"支持"一节。
  **仍缺 `frozenset`**（`frozenset({1, 2})` 报 `NameError`）。
* 集合元素顺序按插入序，CPython 按哈希序（`{3,1,2}` 打印 `{3, 1, 2}` vs `{1, 2, 3}`）；
  但 `==`/`!=`/子集比较是**按内容**算的（v4.51 起），所以 `{1, 2} == {2, 1}` 是 True。
* `{[1]}` 不报 `unhashable type`。

**函数 / 类 / 异常 / 模块**
* 关键字参数只支持用户函数/方法（`f(1, c=9)`）；内建支持 `sorted(x, reverse=True)` 与 **`sorted(x, key=…)`（v4.57）**，以及 **`min`/`max` 的 `key=`（v4.123 P196）**——key 可以是 lambda、用户函数，或 `len`/`abs`/`str` 这类**内建名**（单 token 形式），两个关键字**任意顺序**、可同时给。裸名字的 math 函数只支持单实参（`pow`/`fmod` 用 `math.pow`）。
* `*args` / `**kwargs` 已支持（v4.44）；`def f(*a, **k)` 可以同时收。**调用侧的星号展开（v4.92 P165）**：
  `f(*xs)` / `f(**d)` 都支持（用户函数）——`*xs` 接受列表/元组/集合/生成器/字符串（按字符）/字典（按键），
  与普通实参、关键字混用（`f(1, *[2], **{'c': 3})`、`f(c=1, *[9, 8])`）；`**d` 要求字典、键必须是字符串
  （`TypeError: keywords must be strings`）；类型不符报 CPython 的
  `TypeError: f() argument after * must be an iterable, not int` /
  `… after ** must be a mapping, not tuple`。**内建 `print` 也支持 `print(*xs)`（v4.93 P166）**：
  与普通实参/`sep=`/`end=`/多个解包混用都对，字典按键、字符串按字符、空解包打印空行、
  类型不符报 `TypeError: print() argument after * must be an iterable, not int`。
  其余内建（`max(*xs)`/`min(*xs)`/`sum(*xs)`）、内建的 `**`、方法调用（`obj.m(*xs)`）仍**不支持**。
* `enumerate` / `zip` 已支持（v4.41）；本项清单已经清空（`sorted(x, key=…)` 见 v4.57）。
* `sorted(x, key=…)`（v4.57）的边界：**元素是实例/函数/类**时报 `TypeError: sorted() key function
  cannot receive this value`（这些值没有字面量形式）；**键**要全数字或全字符串（布尔按数字算）。
  **元素/键是元组、列表**时按 CPython 的字典序排（v4.65 P138：逐元素比、第一个不同处定胜负、短前缀更小；
  `min`/`max` 同样），`sorted([(2,'b'),(1,'a')])`、`sorted(xs, key=lambda x: (x % 2, x))` 都对；
  混排（数字与字符串、`None`）报 CPython 措辞的 `'<' not supported between instances of 'X' and 'Y'`。
  **嵌套调用已支持（v4.64 P137）**：`sorted(sorted(xs, key=…), reverse=…)` 以前报
  `SyntaxError: parentheses`（内层调用把钩子的全局解析状态冲掉了），现在钩子把 29 个标量压进 `P4Stk`、
  退出前逆序弹回，探针 `_work/cmp47/d200.json` 8/8。残留：key 函数里再调用一次**带关键字**的 sorted 时，
  `srtkey` 的三个工作列表不在栈里（`d200` N5 现在通过，但时序靠运气）。
* 继承已补齐（v4.44 方法复用 + **v4.54 P127** + **v4.62 P135** + **v4.63 P136**）：`class B(A)` 复制父类方法与类属性、
  子类可覆盖；**`super().方法(…)` / `super().__init__(…)`**、**多继承 `class C(A, B):`**、**菱形继承 `class D(B, C)`**、
  **用父类名显式回调 `A.hi(self)`**、**`类名.方法(实例[, 参数])`** 都可用（探针 `_work/cmp47/t144.json` 16/16、
  `d156.json` 5/5、`d158.json` 8/8、**`d191.json` 8/8**）。多级传递继承成立（`class C(B)` 拿得到 `A` 的方法与类属性）。
  **C3 线性化（v4.62）**：每个类在 `class` 语句处用 C3 算法算出自己的 MRO（`ClsMro`），`super()` 沿**实例所在类**的
  MRO 找"当前方法所属类的下一个"——所以 `D(B, C)` 里 B 的 `super()` 会走到 **C** 再到 A（`d159` E4 `DBCA` ✓）。
  **拷贝也按 MRO（v4.63）**：方法/属性表只抄每个类**自己**定义的那一份（属性用归属列 `IAttrOwn`、方法用
  `ClsFn1` 边界），方法倒着走 MRO、属性顺着走——所以"中间类不覆盖、下一个类覆盖"（`d191` D2）与菱形属性（D5）都对。
  仍缺：`e.args`（消息在隐藏属性里）、类方法/静态方法装饰器。（~~内建异常类的构造~~ 现在可用：
  `raise IndexError('boom')` 会被 `except IndexError as e` 接住并打印 `boom`；~~`super()` 钩子只认"整段就是
  `super().m(...)`"~~ 也已放宽——**v4.68 P141** 把链式切分改成"**最后一个**深度 0 的 `.`"，于是 `super().m().n()`
  与"一个表达式里两个 `super()`"都能用；在子类 `__init__` 里用局部变量给父类 `__init__` 传参在 v4.58 修好
  （`d160`/`d161` 全绿）。）
* **`sorted(x, reverse=…)` / `sorted(x, key=…)`（v4.42 P101 / v4.57 P130 / v4.64 P137）**：一个或两个关键字、
  任意顺序、输入可以是集合；**嵌套调用（`sorted(sorted(xs, key=…), reverse=True)`）自 v4.64 起可用**——
  钩子把 29 个解析状态标量压进 `P4Stk`、退出前逆序弹回，探针 `_work/cmp47/d200.json` 8/8。
  仍缺：key 函数里再调用一次**带关键字**的 sorted 时，`srtkey` 的三个工作列表不在栈里
  （时序靠运气）。（~~元素本身是元组/列表的排序~~ **v4.65 P138 已修**：新增 `lcmp` 做字典序比较，
  `sorted([(2,'b'),(1,'a')])` 正确，`d168` **6/6**、`d201` **15/15**。）
* `with`（`try/finally` 已支持：v4.45 基础 + v4.50 的跳转/`except+finally`，探针 `_work/cmp47/t123.json` 29/29）。
* 已知边界：`try/except/finally` 里多个 `except` 子句已按顺序匹配（v4.59 P132）；元组子句也已支持
  （v4.60 P133）。`except (A, B)` 里写**未定义的名字**现在会抛 `NameError: name 'X' is not defined`
  （v4.67 P140：`cknames` 在**匹配期**校验每个候选子句的名字，内建异常名扫 `ExcNames`、其余走 `iscls`），
  与 CPython 一样是"子句表达式在匹配时才求值"——`try:` 没抛异常就不会碰子句名字。
  尾巴里 `raise` 的错误会替换掉原来寄存的错误（与 CPython 一致），但报错行号指向尾巴那一行。
* 任意值当函数调用 / 任意值的属性访问现在都按 CPython 报**运行期**错误（v4.68 P141）：`1()`
  → `TypeError: 'int' object is not callable`（`'a'()`/`1.5()`/`True()`/`[1]()`/`{'a':1}()`/变量里
  的非函数同理），`(1).foo` / `'a'.foo` / `[].foo` / `None.foo` / `(1, 2).foo`
  → `AttributeError: '<类型>' object has no attribute 'foo'`；实例缺属性 `A().foo`
  → `'A' object has no attribute 'foo'`，类缺属性 `A.zz` → `type object 'A' has no attribute 'zz'`。
  **零实参调用也已支持（v4.69 P142）**：`list()`→`[]`、`str()`→`''`、`int()`→`0`、`float()`→`0.0`、
  `bool()`→`False`、`tuple()`→`()`、`dict()`→`{}`、`zip()`→`[]`（立即求值扩展）；`len()`/`abs()`/`sorted()`/
  `max()`/`sum()`/`type()`/`round()`/`pow()`/`divmod()`/`range()` 等按 CPython 报 `TypeError`；
  `nosuch()` 报 `NameError: name 'nosuch' is not defined`；`set()`/`input()`/用户函数/类/变量一律不变。
  **类型构造器当表达式（v4.70 P143）**：`tuple(x)`（列表/元组/集合/生成器/字符串 → 元组，
  `tuple('ab')` → `('a', 'b')`，非可迭代对象报 `TypeError: '<类型>' object is not iterable`）、
  `range(n)` / `range(a, b)` / `range(a, b, step)` 立即求值成列表（于是 `list(range(3))`、`sum(range(4))`、
  `list(range(3))[::-1]` 都能用；`step == 0` 报 `ValueError: range() arg 3 must not be zero`）；
  `for i in range(...)` 与推导式里的 `range` 走原来的快路径，不受影响。
  **`dict(x)`（v4.71 P144）**：从键值对序列建字典——`dict([(1, 2), (3, 4)])`、`dict([[1, 2]])`、
  `dict(((1, 2), (3, 4)))`、`dict(pairs)`、`dict(已有字典)`（复制）；**重复键保留首次位置、最后一次的值**
  （`dict([(1, 2), (3, 4), (1, 5)])` = `{1: 5, 3: 4}`）；字符串键、元组键都可查；报错对齐 CPython：
  `TypeError: '<类型>' object is not iterable`（源不可迭代）、`TypeError: object is not iterable`（元素非序列，
  裸消息）、`ValueError: dictionary update sequence element #0 has length 3; 2 is required`。
  **`dict` 的关键字实参（v4.75 P148）**：`dict(a=1, b=2)`、`dict(a=1)`、`d = {'x': 9}; dict(d, a=1)`
  （映射 + 关键字混合，顺序上与 CPython 不同：MiniPy 把关键字记录放在前面）；重复关键字报
  `SyntaxError: keyword argument repeated:`，多个位置实参报
  `TypeError: dict expected at most 1 argument, got 2`。
  **字典当序列遍历（v4.76 P149，v4.84 P157 起含 `sum`）**：字典可以喂给 `list` / `tuple` / `set` /
  `enumerate` / `zip` / `sorted` / `min` / `max` / `any` / `all` / **`sum`**，取的是**键**
  （`list({'a': 1, 'b': 2})` → `['a', 'b']`，顺序即插入序；`sum({1: 2})` → `1`，字符串键则抛
  `unsupported operand type(s) for +: 'int' and 'str'`）；`len(d)`、`for k in d`、`d.keys()`、`str(d)`、
  `print(d)` 语义不变。
  **`dict(**d)` 解包（v4.84 P157）**：`dict(**d)`、`dict(b=2, **d)`、`dict(**d, **e)`、`dict(**{})`；
  非字典报 `TypeError: dict() argument after ** must be a mapping, not int`，键与已有关键字撞名报
  `TypeError: dict() got multiple values for keyword argument 'a'`。
  **仍缺**：视图的**集合语义**（CPython 的 `d.keys()` 能和集合比、能做 `&`/`|`/`-`/`<`；
  MiniPy 现在只当列表用）、
  字典的大小比较 `d1 < d2`（CPython 报 `TypeError`，MiniPy 仍按原始记录串比）、
  `{'a': 1} == {'a': 1.0}`（类型标记不同 ⇒ `False`；CPython `True`）、
  其余内建的 `*`/`**` 解包（`max(*xs)`/`min(*xs)`/`sum(*xs)`）与方法调用解包（`obj.m(*xs)`)、
  `print(*xs)` 元素是自定义对象时走 `__str__`、`f(**d)` 的重复键检查
  （CPython 报 `got multiple values for keyword argument`）；
  `print(range(3))` 打印 `[0, 1, 2]`
  而不是 `range(0, 3)`（立即求值扩展，与 `zip()`/`enumerate()` 同类）。
  元组方法：`len`/索引 + `index`/`count` 已支持（v4.67 P140，`(1, 2, 1).count(1)`、`(1, 2).index(2)`，
  找不到时报 `ValueError: tuple.index(x): x not in tuple`），其余方法报
  `AttributeError: 'tuple' object has no attribute 'append'`（与 CPython 同措辞）。
* `for a, b in <生成器>` 已支持（v4.53，`t143.json` 7/7）；元素个数不匹配时抛 `ValueError: not enough values to unpack (expected 3, got 2)`（v4.61 起带上期望/实际个数；源是字符串时按 CPython 只写期望个数）。

* `import os` 之类（有清晰报错 `ImportError: no module named os`）。

## 4. 运行环境自身的限制（不是语法）
* 步数上限 `10000 + speed*90000`；递归深度上限 96；函数体内 20000 步上限。
* 控制台是 30 列 × 9 行的网格（自动换行）；变量面板 4 行、每行 30 列（超出显示 `...`）。
* 控制台/面板绘制用的字母 costume 只有 ASCII 字形。
* 单次 RUN 的执行方式：默认 warp 快跑（`mode=0`），STEP 逐行（每点一次一行，函数体内也是），
  SP 切到慢速（1 行/帧）。**设断点会让整跑退化为逐行**（v4.34 已回退，此条仅留档）。
