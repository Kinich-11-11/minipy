## 1. 浅拷贝 `[:]` / `.copy()` 是深拷贝（纯静默，最该先修）

复制一份后改副本，原对象也被改；二维结构尤其隐蔽。

- `cov3 shallow copy method`：`b=a[:]; b[0].append(2)` → `[[1,2]] [[1,2]]`（应为 `[[1]] [[1,2]]`）
- `cov3 slice copy vs alias`：一维别名串错
- `cov4 dict copy shallow`：`{'a':[1]}` 复制后改内层 → 两边同步
- `covX` 列表切片/`.copy()` 多例、`covC copy is deep`、`gap131 copy deep not shallow`（共约 6 例）

> 学生预期"复制 = 独立副本"，MiniPy 给的是别名。每个数据结构练习都可能踩，且**不报错**。

## 2. 生成器 / `next()` 无迭代器状态（静默后果最重）

容器是"编码字符串 + 别名表"，没有游标；`next()` 不前进、genexp 被当 list 立即求值。

- `cov7 generator next and exhaustion`：`next(g)` 两次 → `a aa`（应为 `a b`，耗尽后 `StopIteration`）
- `cov7 reused after exhaustion` / `short circuit` / `expression vs list comp` / `nested generator` / `comprehension reusing a generator` / `iterator protocol on custom class` / `yield from`
- `covC generator exhaustion` / `nested generator yields`
- `covY generator exhaustion twice` / `nested generator yields` / `comprehension over generator function`
- `gap131 generator exhaustion` / `yield from`（共约 14 例，多静默）

## 3. 返回值别名（仅剩全局列表路径）

嵌套函数返回别名已修；**全局可变列表 append 后返回仍漏**。

- `cov5 function modifying global list` → `[1] [1,2]`（应为 `[1,2] [1,2]`）
- `cov5 augmented assign to global inside function` → `1`（应为 `ule`）
- `cov5 default mutable argument` → `[1] [2]`（应为 `[1,2] [1,2]`）

> 与已修的 `d[k]=v` 同属一张别名表，沿同路补"全局可变状态"即可。

## 4. 异常实例模型（仅剩实例身份/属性）

异常类可捕获已修；拿到的 `e` 仍是消息串而非异常对象。

- `covC exception instance identity` → `False`（应为 `True`）
- `covZ exception instance type` → `False`
- `cov6 custom exception with attributes` → `AttributeError: code`
- `cov6 exception str and repr` → `NameError: ValueError`
- `cov6 exception hierarchy catching base`、`gap131 type e equals E` / `except as e is exception object` / `custom exception init attr`（约 8 例）

> ⚠️ 改 `raise`/`except`/`trycatch` 共用 `"<Class>: <message>"` 消息串（见 `p129.txt`）时，必须保证 `except` 匹配仍只看前缀，否则"错抛了却抓不到"（v4.159 踩过）。

## 5. 闭包返回 / `nonlocal`（部分已修，剩返回+nonlocal）

lambda 多参/默认已修；闭包返回的函数调不起来、`nonlocal` 报错。

- `covC closure returned and called` → `SyntaxError`
- `covC nonlocal keyword` → `SyntaxError`
- `covY closure returned lambda called` / `closure returned nested def called` → `NameError: n`
- `gap131 closure returned` / `return value nested call direct` / `nonlocal counter`（约 7 例）

## 6. 运算符重载 `__add__/__eq__/__lt__`（len/getitem 已修）

- `cov6 operator overloading add and eq` → `TypeError: unsupported operand type(s) for +: 'V' and 'V'`（CPython 给 `V3 True False True`）
- `cov6 operator overloading lt for sort` / `len getitem`(仍 STILL) / `calling method stored in variable`
- `gap131 operator overload add` / `operator overload lt sorted`（约 6 例）

> 与 #10 字典内 repr 共用"方法分派表"，修此条时顺手清 #10 最划算。

## 7. 内建名当值（`type(1)==int`、`apply(str,4)`）

- `cov5 function as argument` → `NameError: str`
- `cov5 builtin type names` → `NameError: int`
- `gap131 builtin as value apply str` / `type identity equals int`（约 4 例，多为 `NameError`）

## 8. `max(default=)` / `pow` 单参

- `covZ max with default` → `SyntaxError: expression`（应为 `2`）
- `covZ pow single arg` → `NameError: name 'pow' is not defined`（应为 `TypeError: pow() missing required argument 'exp'`）
- `covD pow one arg` / `pow name alone`、`gap131 max with default` / `min with default empty` / `pow one arg`（约 7 例）

## 9. 隐式拼接 / 尾逗号 / 续行

- `cov9 implicit string concatenation` → `SyntaxError: expression`（应为 `ababc`）
- `cov9 implicit concatenation across lines` / `trailing comma in call and literal` / `backslash in string is not continuation`
- `gap131 implicit string concat` / `trailing comma list` / `backslash continuation in string literal`（约 7 例）

## 10. 字典内 `repr`（极窄尾巴）

- `cov6 class str and repr` → `{'k': <Thing object>}`（应为 `{'k': Thing!3}`）

> str/repr 分派 90% 已修，仅字典值位置未走 `__repr__`。

## §10. 暂缓项（覆盖也广，但文档已声明 / 数值底座 / 低频）

| 条目 | 现状 | 缓放理由 |
|---|---|---|
| 大整数精度 | `cov1 divmod big`→`49`(应为56)、`int to str of very large`→`21`(应为31) 等 5 例 | 文档 §2 已声明（JS number 失真）；动底座成本≫收益 |
| 十进制浮点模型 | `cov10 sum of floats`→`0.6000000000000001`、`cov1 round`→`2.68`(应为2.67) | 同上主动取舍 |
| 浮点显示 | `cov1 float literal trailing zeros`→`3.50`、`cov10 float printing`→`2.50` | 触面广，等数值批次 |
| `print(sep='',end='')` | `covD` → 空（应为 `xy`） | 极窄边界 |
| genexp 立即求值 | `covZ genexp is a list`→`[0,1,2]` | 文档主动声明偏差 |
| 嵌套 format / format 异常类型 | `cov2 format nested spec`、`cov10 format negative and sign` | 低频高级用法 |
| `repr` 回退 / `None` 返回值 / `frozenset` | `covY repr fallback`→`<NoStr object>`、`cov4 frozenset`→`ne` | 文档 §2/§3 已列 |
| `sorted(字典, key=内建名)` 未排序 | `covC sorted dict with key lambda`、`covZ sorted dict with key lookup` | 与 #7 内建名同源，等 lambda 批次 |
| `two-level +=` / `assert` / `finally` 路径 | `cov4 two level plus assign`→`SyntaxError`、`cov6 assert`/`finally` | 低频或文档偏差 |
| realistic 用例 | `cov8 run length encoding`→静默错、`cov8 class based bank`→`SyntaxError` | 根因落生成器/解析，随对应条解决 |
