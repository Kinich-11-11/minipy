## 二、按领域的其余确认项

**容器语义**
- `a[:]` / `a.copy()` / `d.copy()` 是**深拷贝**：`a=[[1]]; b=a[:]; b[0].append(2)` 后 `a` 仍是 `[[1]]`（CPython 是浅拷贝，`a` 也变）。文档在讲「别名语义」，实为反例。
- 不可哈希键不被拒绝：`d[[1]] = 2`、`s = {[1]}` 都不报 `TypeError`（CPython 报）。
- 切片步长赋值不支持：`a[::2] = [9,9]` → `SyntaxError: expression`（介绍里声称支持「切片赋值」）。
- `s[::0]` 的 `ValueError` **无法被 `try/except` 捕获**（直接逃出去）。

**dict / set**
- `d.update([('b', 2)])` → `TypeError: 'list' object is not iterable`（可迭代对形式不支持）。
- `sorted(d, key=lambda k: -d[k])` → `TypeError: sorted() requires a list`（裸 `sorted(d)` 正常）。
- `set.pop()` → `AttributeError: set has no method pop`。
- `max([1,2], default=0)` → `SyntaxError: expression`。

**生成器**
- 嵌套生成器**互相泄漏**：`inner()` 产 1,2、`outer()` 只应产 10,20，实测 `[1, 2, 10, 20]`。
- 耗尽的生成器会**重新开始**：`list(g)` 两次得到 `[1]` `[1]`（CPython 第二次 `[]`）。
- `next()` 内建不存在（`NameError`）。
- （生成器表达式立即求值成列表是**文档已声明**的偏差，不计入。）

**推导式**
- 元组目标不支持：`[v for k, v in [('a', 1)]]`、`{k: v for k, v in ...}`、`{v for k, v in ...}` 全部 `SyntaxError: for <name> in ...`（文档声称列表/集合/字典三种推导式都支持）。
- 只能对列表/range 迭代：`[k for k in d]`、`[v for v in gen()]`、`[i for i in enumerate(x)]` → `TypeError: comprehension needs an iterable`。

**函数 / 作用域**
- **返回的闭包无法调用**：`def adder(n): return lambda x: x+n` → `adder(5)(1)` 报 `NameError: name 'n' is not defined`；`make()()` 报 `SyntaxError: parentheses`（文档声称「嵌套 def + 闭包」）。
- `nonlocal` 不支持（`SyntaxError: unsupported statement`）。
- lambda 两个边界：内联多参 `(lambda a, b: a+b)(1,2)` → `SyntaxError: lambda needs a colon`；带默认值 `f = lambda x, y=10: x+y` → `TypeError: missing argument y`。
- 内建名不是一等值：`apply(str, 4)`、`type(1) == int` → `NameError`（能调用 `int(x)` 但不能把 `int` 当值）。
- `pow` 只是 **2 参特例**：`pow(2,3)` 可以，`pow(2)` / `pow(2,3,5)` → `NameError`，`pow(2,0.5)` → `ValueError`（文档内建列表里写着 `pow`）。
- `UnboundLocalError` / `LookupError` 名字不存在。
- `map` / `filter` 不存在。

**类**
- `str(obj)` 与 f-string **不走 `__str__`**（`print(obj)` 走）：`class Q: def __str__(self): return 'Q!'` → `str(Q())` 与 `f'{Q()}'` 都给 `<Q object>`；`__repr__` 完全无效（`print([R()])` → `[<R object>]`）。
- 类体之外给类属性赋值报错：`class C: k=1` 然后 `C.k = 2` → `AttributeError: only instances have attributes`（方法里 `D.k = v` 同样）。
- **类级可变属性不共享**：`class B: xs=[]`，`b1.xs.append(1)` 后 `b2.xs` 仍是 `[]`（CPython 是 `[1]`）。
- **多继承第二基类不成立**：`class Dd(B, Cc)` 后 `isinstance(Dd(), Cc)` 与 `issubclass(Dd, Cc)` 都是 `False`（文档声称按 C3 线性化）。
- `type(e) == E` 为 `False`。
- 取方法值 `m = t.f` 不支持；`return self.data.pop()` 返回的是**对象本身**（`<S object>`）。
- 运算符重载（`__add__` / `__len__` / `__getitem__` / `__lt__`）全部不支持，`sorted(自定义对象列表)` 因此失败。

**异常**
- `except X as e` 拿到的**不是异常对象**：`type(e)` 是 `<class 'str'>`，`isinstance(e, Exception)` 为 `False`。
- 自定义异常：`isinstance(e, MyErr)` 与 `isinstance(e, Exception)` 都是 `False`；`__init__` 里 `self.code = code` 报 `AttributeError: 'str' object has no attribute '0'`。
- `finally: return` 在**异常路径**不吞异常（正常路径可以）。
- `assert 1 == 2, 'msg'` 的 message 丢失。

**语法 / 布局**
- 隐式字符串拼接 `'a' 'b'` 不支持（`SyntaxError: expression`）。
- 字面量尾逗号 `[1, 2,]` → `SyntaxError: missing expression`。
- 嵌套解包目标不支持：`(a, b), c = (1, 2), 3` → `NameError: a`；`a, (b, c) = 1, (2, 3)` → `SyntaxError: invalid assignment target`；`for i, (a, b) in enumerate(...)` 报 `ValueError: not enough values to unpack`。
- 多行语句吞掉续行导致**报错行号偏移**（前两轮已定位：行号 = 失败语句物理行 − 该语句之前被执行的多行语句的续行数）。

**数值**
- `abs(True)` → `TypeError: numeric argument`；`abs(-0.0)` → `0`（int）。
- `float('inf')` / `float('nan')` → `ValueError`。
- `sum([True, True])` → `TypeError`。
- int/float 混合运算丢浮点类型：`1 + 1.0` → `2`、`2 * 1.5` → `3`、`sum([1.5, 2.5])` → `4`。
- `round(2.5, 0)` → `2`（int，应为 `2.0`）；`round(1234.5, -2)` → int。
- `divmod(7.0, 2.0)` → `(3, 1)`（应为 `(3.0, 1.0)`）。
- `float('-0.0')` → `0.0`（负号丢失）。
- 字面量尾部零原样打印：`print(3.50)` → `3.50`（CPython `3.5`）；`round(26.0, 2)` → `26`。
- 大整数按 JS double（文档已声明），但副作用比文档写的广：`divmod(10**18 + 7, 1000000007)` 余数 `49`（CPython `56`）。

## 五、建议修复优先级

1. **容器原地写**：`d[k] = v` 覆盖已有键摧毁后续条目、`t = a[i]` 槽位别名、嵌套函数修改对返回值不可见 —— 这三条让任何「累积/排序/记账」类程序都不成立（本报告 §1 的 #5/#7/#8）。
2. **`bool(空容器)`** —— 静默走错分支，且是单点修复。
3. **`**` 结合性 / 一元负号优先级 / `sort(reverse=True)`** —— 都是单点语义错误。
4. **`dict` 的 `in` 遇 `.` 报错** —— 修 `in` 的容器类型判定即可。
5. **推导式与 `for` 的元组目标、生成器嵌套/耗尽**。
6. **`__str__`/`__repr__` 与异常实例模型**（`except as e` 拿到 str 是根因之一）。
7. 文档同步：把 §三 表格里那些「声称支持但实测不支持」的条目改成已知缺口。
