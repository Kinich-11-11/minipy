# MiniPy 已知问题清单（基于 v4.200 实测）

**构建**：`MiniPy_v4.200.sb3`（2026-10-27，911 KB，33,129 块）
**对照**：CPython 3.14（oracle），15 套 581 例 + 补充 82 例，串行、各自私有临时文件。
**总量**：
- 581 例中 **55** 失败（v4.199：63）
- 82 例补充中 **15** 失败（v4.199：18；其中 `pow one arg` / `pow single arg` 2 例 MiniPy 已对，只是用例缺 `try/except`，非真问题）
- **真实失败合计 ≈ 68**（v4.199：≈79）

> 排名判据：**影响体验（静默错 ≫ 报错） × 覆盖广度（学生日常写法出现频率）**。
> 所有结论均由 `runall.mjs`/`run_iso.mjs` 实测，逐例用 `cmp131.cjs`/`gdiff.cjs` 核验。

### 已修掉 11 例（全部属于旧清单 #1 例外实例模型）
- `cov6 custom exception with attributes`、`cov6 exception hierarchy catching base`、
  `cov6 exception str and repr`、`cov6 type of instance and name`
- `covC exception instance identity`、`covY type equality with class`
- `covZ custom exception with init attrs`、`covZ exception instance type`
- 补充：`LookupError name exists`、`custom exception init attr`、`except as e is exception object`

### 本轮修正的误判 / 坑
- `callfn` 的类名判据是 Scratch 的 `contains`（**子串**）。`ClsName` 以前是空的所以从未暴露；
  本轮把内建异常名注册进去后，`FloatingPointError` 里含 `int`、`...OverflowError ValueError`
  里含 `len`，于是 `len()/int()/type()/float()` 被当成类构造返回 `<len object>`。已改为精确匹配。
- `clsmro` 按 `ClsName` 的下标读 `ClsMro`，注册新类名后 MRO 整体错位（`super()` 链断），
  必须同步补齐 `ClsMro`。
- `raise X(...)` 从来不调用构造函数（只对参数区求值），`__init__` 属性只能靠回退实例，
  这是"能构造但不能 raise"的根因。
- 构建器里的 `IF(cond, a, b)` **只接受两个参数**，第三个会被静默丢弃（本轮踩过一次，
  repr 的非字符串分支整段消失）。

## 1. 闭包返回 / `nonlocal`（剩余约 6 例）

- `covC closure returned and called` → `NameError: n`
- `covY closure returned lambda called` → `NameError: n`
- `cov5 function returning function` → `NameError: n`（`adder(5)` 返回的 lambda 拿不到 `n`）
- `covC nonlocal keyword` / `cov5 nonlocal keyword` → `SyntaxError: unsupported statement`
- `cov5 closure counter attempt without nonlocal` → 输出 `1 1`（CPython 抛 UnboundLocalError）
- 补充 `closure returned`、`nonlocal counter`

> 方向：P14 的帧模型里，函数值只记 `FnLine/FnTlo/FnThi`，没有"捕获环境"的概念。
> 最小可用方案是给每个闭包值记一份 `CloB/CloN/CloV/CloT`（P127 已经有 `Clo*` 表用于 lambda
> 捕获），返回时把外层局部变量按值快照进去；`nonlocal` 再补写回。

## 2. 生成器对象标识（剩余约 8 例）

容器是"编码字符串"，生成器的值也是编码串 ⇒ **两个内容相同的生成器共用一个游标**。
嵌套生成器已由 P490 修好，剩下的都是"对象身份"问题。

- `cov7 comprehension reusing a generator` → `[0, 1, 2] [0, 1, 2]`（应为 `[0, 1, 2] []`）
- `cov7 generator short circuit` / `generator exception propagation` / `generator in for loop`
- `cov7 generator expression vs list comp`、`covY comprehension over generator function`
- `cov7 iterator protocol on custom class`（`__iter__`/`__next__`）
- `covZ genexp is a list`（文档已声明的偏差：genexp 立即求值）

> 方向：给生成器值分配**对象标识**（而不是按内容寻址），`GIt`/`GId` 改成按 id 查。

## 3. 运算符重载 `__lt__` / `len` / `__getitem__`（剩余约 4 例）

- `cov6 operator overloading lt for sort` → `TypeError: '<' not supported…`
- `cov6 operator overloading len getitem` → `SyntaxError: expression`
- `covY sorted custom objects needs lt`、`cov6 class with list of objects and methods`
- 补充 `operator overload lt sorted`

## 4. `format` 高级形式 / 嵌套 f-string（剩余约 4 例）

- `cov10 nested fstring in format` → `KeyError: 'w'`
- `cov10 format negative and sign`（CPython 对 float 用 `d` 会抛 ValueError，属错误路径）
- `cov2 format nested spec and paths`、`cov2 format errors caught`

## 5. 返回值别名（剩余约 3 例，纯静默）

- `cov5 function modifying global list` → 输出旧值
- `cov5 augmented assign to global inside function` → `1`（应为 `ule`）
- `cov5 default mutable argument` → `[1] [2]`（应为 `[1,2] [1,2]`）

## 6. `assert` / `finally` 路径 / 两级 `+=`（剩余约 4 例）

- `cov6 finally swallows return`、`covC finally return on exception path`
- `cov6 assert statements`、`cov4 two level plus assign`（`SyntaxError`）

## 7. 类与对象小尾巴（剩余约 5 例）

- `covY method returns self attribute pop` → `<S object>`（应为 `2`，方法返回值被实例覆盖）
- `cov6 calling method stored in variable`、`cov6 instance in dict and list`（实例 `repr` 缺 `__main__.`/地址）
- `covY repr fallback for print`

## 8. `filter(None, …)` 真值判定（1 例）

- `cov5 builtin map filter reduced` 第二行 → `[1, 'a', None, [], 0]`（应为 `[1, 'a', [0]]`）

> 空的 `None`/`[]` 没有被判为假；`[0]` 被误判为假。`mpkeep` 的真值表要按元素类型逐项对齐 CPython。

## 9. 反斜杠续行（1 例）

- `cov9 backslash in string is not continuation` → `a b`（应为 `ab`）

## §10. 暂缓项（文档已声明 / 数值底座 / 低频）

| 条目 | 现状 | 缓放理由 |
|---|---|---|
| 大整数精度 | `cov1 big int precision`、`divmod big`、`integer division precision`、`cov10 int to str of very large` 等 | 文档 §2 已声明（JS number 失真） |
| 十进制浮点模型 | `cov10 sum of floats`→`0.6000000000000001`、`cov1 round`→`2.68`(应为2.67) | 同上主动取舍 |
| 浮点显示 | `cov1/covX/cov10 float trailing zeros`、`negative zero`、`round returns`、`large and small floats` | 触面广，等数值批次 |
| `print(sep='',end='')` | `covD sep empty with end empty` → 空（应为 `xy`） | 极窄边界 |
| `pow(x)` 报错用例 | `covD`/`covZ pow one arg` | 用例本身缺 try/except，非真问题 |
| `frozenset` | `cov4 frozenset if supported` → `ne` | 文档 §2/§3 已列 |
| `len(range)` / `range` 相等 | `cov5 builtin range forms` → `SyntaxError: parentheses` | 低频 |
| realistic 用例 | `cov8 run length encoding`、`cov8 class based bank` | 根因落生成器/解析 |
| `type e equals E`（补充） | MiniPy 输出 `True`，CPython 抛 `TypeError` | 用例本身不合法（`class E: pass` 不能 raise） |
| `UnboundLocalError name exists`（补充） | 抛出基类 `NameError` | 属异常**产生**侧（局部变量未赋值），不是实例模型 |
