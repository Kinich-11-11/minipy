# 相对 v7，v4 还差哪些代码

全部结论来自无头实测（真实 scratch-vm 加载两个 .sb3 跑用例）：
`features.json`(60 例) + `gaps.json`(50 例) + `focus.json`(7 例)，
原始结果 `feat_*.json` / `gap_*.json` / `focus_*.json`，对照表 `compare.txt` / `gaps_compare.txt`。

## A. v4 完全写不了的代码（写了就报错）

| # | 代码形态 | v4 实际报错 |

## B. v4 能跑但语义不对（这类更隐蔽）

| # | 代码 | v4 | v7（Python 语义） |
|---|---|---|---|
| 1 | `round(0.5)` / `round(2.5)` | 1 / 3（JS 式进位） | 0 / 2（银行家舍入） |
| 2 | `print(4/2)`、`float("1.5")*2` | `2`、`3` | `2.0`、`3.0`（float 有独立 repr） |
| 3 | `print([1, "a"])` | `[1, a]`（不加引号） | `[1, 'a']` |
| 4 | `a=[1,2,3,4]; print(a[1:3])` | 打印内部编码 `N1` / `N4`（**不报错**） | `[2, 3]` |
| 5 | `x = y = [0]; x[0]=1; print(y)` | `[0]`（赋值即拷贝，无别名） | `[1]` |
| 6 | `str(True)`、`True+True` | `1`、`2` | `True`、`2` |
| 7 | `int(' 12 ')` | `ValueError: invalid number` | `12` |
| 8 | `a, b = 1, 2, 3` | `ValueError: unpack count mismatch`（正确） | 静默取前两个（v7 的 bug） |

## C. 两版都写不了（不是 v4 独有的差距）

`1e3` / `0x10` 字面量、`a = 1; b = 2` 分号、`from … import`、`import … as`、
`except (A, B)` 元组捕获、`def f(b=[])` 非字面量默认值、`del a[0:1]` 切片删除、
`d.items()`（v7 返回 None）、`{1,2,3}` 集合（v7 误当 dict）、
`a[0:1]=[9]`（v7 静默算成 `[[9], 2, 3]`）、大整数精度（两版都是 JS number，`2**53+1` 都失真）。

## D. 实现层面：v4 引擎缺的“代码”

| | v4 Interpreter | v7 Interpreter |
|---|---|---|
| 自制积木 | 36 个：`prepare/tokenize/eval/execute/assign/callfn/builtin2/listlit/indexget/methodcall/…` | 10 个：`lex_all / parse_all / compile_all / init_vm / vm_run / print_line / reset_vm / dump_tok / dump_ast / dump_code` |
| 程序表示 | 源码留在列表 `Code`，边扫边算（Tok/Kind/Comma… 9 个临时表） | 分词 → AST → 字节码三张表：`TokT/TokV`、`NdK/NdA/NdC/NdL`、`PcT/PcA..PcE` |
| 调用栈 | 无（不支持用户函数） | `Stk / FrTop / FrKind / FrRet / FrEnv / FrBase` |
| 作用域 | 只有全局 `Names/Values/Types` | `BindName/BindVal/BindNext` 环境链 + 帧 |
| 对象模型 | 值 = 「类型字符 + 文本」编码串（列表用 ASCII 31 分隔） | `ClName/ClBase/ClMap`（类）、`MapHead/MapParent/MapKind`（dict/实例） |
| 异常 | 无 | 异常表 + `XSET/XCLR/TRY/ENDTRY/ISINST/RERAISE` 指令 |
| 模块 | 无 | `S!math / S!json / S!time` |

也就是说，v4 缺的不只是几条语句：**它没有 AST/字节码、没有调用栈、没有类与异常表、没有 dict/tuple 值类型、没有模块表**——
这些正是 v7 那 92090 个积木换来的东西。
