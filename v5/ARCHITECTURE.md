# 核心架构与迁移记录

## 基线审计：输入、功能和边界

冻结的是 v4.267 **作品快照**，不是一次从 v4.1 重放到 v4.267 的历史工具链。冻结提交保留发布说明、最后一轮生成器和基准输入供考证；v5 构建只读哈希匹配的 v4.267，不运行这个历史生成器。基线自报的 `meta.agent` 仍为 v4.259，不能用于鉴定版本。`reports/baseline-inventory.json` 给出每个事件/过程的静态清单；每条 `calls` 是过程级调用点计数，`reads/writes` 是按名字归集的直接数据引用（读改写不作完整数据流证明）。`lexicalCandidates` 是与字面量比较的名字，不是 CPython API 兼容性清单。

| 作品表面 | v4.267 中应保留的能力；验证入口 |
|---|---|
| 编辑器 | 舞台 Code/Output，Controller 编辑/运行/单步/停止，TextRenderer 字形和原始行标记；`editor`、`lifecycle`、资源摘要。两侧不共用可写源文本。 |
| 表达式/语句 | 算术、格式化、比较与短路、解包/链式赋值、索引切片、if/elif/else、循环及 break/continue/else、assert、del、导入；`report`、`edge`、`coverage`。 |
| 值与对象 | 数字（包括大整数与复数路径）、字符串与 Unicode、列表/元组/字典/集合、对象身份与复制、类型方法；`protocols`、`aliases`、`coverage`。并非所有可变对象组合都一致。 |
| 调用与作用域 | 默认/关键字/星号参数、递归、lambda、闭包、global/nonlocal、单元解析、`__name__`；`main`、`semantic`、`objects`。 |
| 类与控制转移 | 类、实例、继承、属性、绑定方法、特殊方法；try/except/else/finally、raise、with、异常组路径；`report`、`archive`、`archive-rest`。 |
| 惰性计算 | 迭代器、生成器与恢复、推导式、生成器表达式、字典视图；`protocols`、`editor`、`coverage`。 |
| 模块 | 有限子集，不是完整标准库：math、cmath、time、datetime、random、statistics、re，以及 collections（含 deque、Counter）、functools、itertools、heapq、json 的路由；以具体过程/程序为准。文件系统模块如 os、动态 exec 不因本轮而新增。 |
| 压力与外部条件 | 1000 工作行、每工作行 2000 字符的既有检查，另有执行步数及函数内部步数限制。展开/辅助行不是原始物理行。随机、时钟和对象地址不应当承诺为恒定输出。 |

## Scratch 执行模型

```text
Controller / Code（用户文本） → RUN → 本次运行的输入快照
  → 续行合并 → 单行 suite 拆解 → 分号拆分 → emit(工作行, 原始行)
  → prepare：缩进检查 + 配对控制边 → pc / boundary / tokenize / execute
  → 表达式 / 名称或对象分派 / 函数或模块
  → 原有 Output / error / 状态面板；HALT 仍是可中断的单独事件
```

Stage 的 UI 契约保留。Interpreter 拥有运行数据；`Src267` 是逻辑执行行，`SrcMap267[i]` 是编辑器的 **1-based** 原始行号；后者放舞台供 TextRenderer 读取。动态生成器/deque 辅助行不伪造来源。用户程序错误通过原有 `error`/异常栈传播，普通未捕获异常的 `Line` 用物理行；无映射时标记内部行。构建图异常则抛宿主错误并中止发布，不写半成品。调试时可观察 `pc, Ends, Elses, FnStack, FrGen, VSave, LSave`，无需在积木里加调试分支。

## 变更账本：八个迁移模块

| 模块 | 选择、保证和代价 |
|---|---|
| `ownership` | v4 的宽松结构检查漏掉前向环、多父节点、错误反链、失效 shadow 和虚假空 substack。以实际前向执行路径为准构造编辑器可表示的树，为多重所有者复制必要子树（**增加 2081 块**，不靠破坏某个分支减少体积）；未激活生成器的残留 yield 回边改为显式错误，未知环拒绝构建。按现有 ID 修正两个显示名；保留所有造型及字形顺序。另有 40 处控制字符/CR 字面量不能无损通过编辑器 XML；其原值存作只读初值，用可编辑的命名变量读取，不替换字符或删文本。 |
| `source` | 删掉 join/expand/split 各自的整表搬运和固定三遍展开。保留成熟的扫描器，由单行 `suite`/`split` 将文本和位置一起交给唯一 `emit`；只有确实包含分隔符才走相应扫描。仅嵌套 suite 的后续片段可能继续处理，兼容上限三层。三引号续行保留 LF 和缩进；suite 扫描识别单引号。保留一次输入快照作运行隔离。不宣称长续行已有严格线性复杂度。 |
| `frames` | `scalars`、`vectors` 是调用帧布局的唯一定义。139 个标量顺序入 VSave，逆序从末端还原；15 个向量逆序写元素，最后写长度，出栈时直接按原顺序重建。无需维护两张基址表，不用在 142 个独立恢复表达式里同步手写偏移。保留 `pend` 两侧的 UI 状态保护、单独的控制/生成器栈，不将其混为值栈。新帧仍须复制部分解释器状态，并非零成本。 |
| `calls` | 合并两套内置实现为 `dispatch callable(fn, lo, hi, fast)`；RUN 经 warp 入口，STEP 无强制 warp。参数区间、返回寄存器及异常协议不变；轮询输入与原生 ask/answer 是真正的传输差异，保留在输入边界。消耗迭代器从当前位置开始，运行和单步不再维护不同的算法。 |
| `layout` | 由反复前后扫描/重新分词改为单趟缩进栈：每个有效行只入/出栈一次；弹出时补写 `Ends`，同缩进分支补写 `Elses`/`LoopElse`，未闭合行以 `n+1` 为默认出口。空白/注释不入栈，语法错误优先级不因关联合并而提前。配对本身 O(n)，临时空间 O(嵌套深度)，**不是整个解释器 O(n)**。语法检查和 except* 的专项验证仍在。 |
| `names` | 将 11 个行索引/集合查询入口从一个构建期算法生成。Scratch 列表查找先取不区分大小写的候选，再逐项精确核对，发生大小写碰撞可继续向后。不缓存可能因作用域切换/删除而失效的行号；成员查询和返回行号保持不同结果寄存器。最坏仍为线性。 |
| `owners` | 模块级真别名接入函数参数/闭包已使用的可变单元关系；浅复制不是同一根对象，解绑不是修改原对象。删除名称先解除关联，再设置未绑定标志；避免删除一个名字使另一个名字变成未定义。没有简单地让所有读取都信任某一份序列化快照：该试验曾通过参数用例，却使归并排序错误，故未合入。 |
| `state` | 从所有外部帽子遍历静态自定义积木调用，删除不可达的 5 个私有过程。只在私有暂存有一个写入、一个紧随其后的谓词读取且未被监视时前递，消除 132 个中转。全工程检查字段、内嵌变量/列表、监视器，再删除无引用的 Interpreter 声明。没有按版本号、名字长短或“看起来多余”来删积木。 |

## 保留的内部协议与剩余债务

- `Tok/Kind` 同行对齐；`pc, Indents, Ends, Elses` 定义执行位置和控制边。`execute` 和递归的 `evalCtx828` 仍是大过程，并未谎称已替换为新字节码虚拟机。修改语法时先写组合程序和物理行回归，再查 `source`、`layout` 和相应执行消费者。
- `ev/evtype` 是既有表达式 ABI；`Names/Values/Types/Show` 是可检查的可见绑定表，`CellKey/CellV/CellT` 处理活跃词法绑定；可变对象存在 `RefKeys826/RefIds826/RefData826` 等标识表和序列化负载。框架没有把整个堆迁移为一种编码。不要把列表“内容相等”当作“同一对象”。
- `FnStack/FrGen` 及专用循环/异常/生成器栈描述控制状态。`fpush/fpop` 仅负责同步调用溢出寄存器和暂存向量。添加帧槽只改一处 schema；新增控制信号不能偷偷借用普通值寄存器。
- 多个历史运行路径仍按表名/类型标签分派，Unicode 精确匹配仍依赖解释器的造型表。既有动态 helper 和有限标准库实现也仍在。新事务不依赖数百个历史补丁，但冻结基座内未重写的运行逻辑仍需逐块迁移。
- Scratch 本地及舞台存储、warp/非 warp、RUN/STEP/HALT、输入轮询和原生 ask 是可移植性的边界。检查了两种 VM 的指定用例；未以旧版 CCW 网页的通过记录替代对新作品的网页验收。
